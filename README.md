# lipreading-data-guide
A collection of tools and guides to prepare popular lip reading datasets into a simple, standard format for easier model training.

## Available Datasets

- **LRS2/**: LRS2 dataset preparation and processing scripts
- **LRS3/**: LRS3 dataset preparation and processing scripts  
- **LRS_Combined/**: Tools to combine prepared LRS2 and LRS3 datasets
- **Phones/**: Phoneme conversion tools for enhanced training
- **TCD-TIMIT/**: TCD-TIMIT dataset preparation scripts
- **WildVSR/**: WildVSR dataset preparation scripts

## Getting Started

Please refer to individual dataset folders for data processing and cleaning instructions for the respective datasets. Each folder contains detailed README files with step-by-step preparation guides.
